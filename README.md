# Batman Button 🦇

An interactive recreation of the viral Batman button micro-interaction.

## ✨ Features
- **Idle State**: Custom textured dark button with `"i'm batman"` and soft depth shadows.
- **Forward Animation**:
  - Small bat silhouettes peel off the edges, leaving realistic bite-mark cutouts.
  - The button core fractures and shatters outward into realistic polygonal shards.
  - Bats orbit in a natural circular swirling vortex.
  - Bats converge along contour points to assemble the iconic Dark Knight metallic Batarang.
- **Reverse Animation**:
  - Clicking the Batarang shatters it back into bats and reconstructs the button.
- **Zero Dependencies**: Pure HTML5 Canvas & vanilla JavaScript.

## 🚀 Running Locally
Open `index.html` directly in any modern browser, or run:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
